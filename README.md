A program that writes one brutally honest but still polite out-of-office
auto-reply — a single sentence of at most 200 characters — to
`/output/entry.txt`.

The reply admits something a real employee would only say privately
(an inbox of 1,400 unread messages answered at midnight) while staying
warm and professional enough that a manager would let it stand, and it
lands on a quotable turn of phrase: "once I'm back and human again."

## Run

```sh
python3 main.py
```

It writes `entry.txt` under `$MAKEFUN_OUTPUT_DIR` (default `/output`).
